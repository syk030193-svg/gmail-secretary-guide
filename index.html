PERSONAL EMAIL ASSISTANT

메일을 정리하고,
답장은 승인받아 보냅니다.

운영자 본인의 Gmail을 분류하고 요약·답장 초안을 Slack 개인 대화로 전달하는 개인용 Windows 프로그램입니다.

이 사이트는 공개 안내문입니다. 메일을 읽거나 계정을 연결하는 기능, 공개 가입 및 메일·초안 표시 기능은 제공하지 않습니다.

Gmail 비서가 하는 일

01 · 분류

받은 메일과 관련 대화를 확인해 필요한 라벨을 복수로 추가합니다.

02 · 검토

요약과 답장 수신자·제목·본문 전문을 지정된 사용자의 Slack 개인 대화로 전달합니다.

03 · 승인

사용자가 ‘보내기’를 선택한 최신 초안만 Gmail로 발송합니다. 수정 후에는 다시 승인받습니다.

답장 필요 · 일정·마감 · 청구·영수증 · 배송 · 뉴스레터 · 확인 필요

기존 라벨과 읽음 상태를 유지하며 메일을 자동 삭제하지 않습니다. 조치할 내용이 없는 명확한 뉴스레터만 Slack 전달 성공 후 해당 메일 단위로 보관합니다. 첨부파일은 파일명과 존재 여부만 확인하고 내용을 읽지 않습니다.

Google 권한을 요청하는 이유

gmail.modify 권한으로 메일·대화 내역과 기존 발신 기록을 읽고, 라벨을 추가·해제하며, 조건에 맞는 뉴스레터를 보관하고 승인된 답장을 발송합니다. 프로그램은 이 권한의 사용을 설명한 기능으로 제한합니다.

프로그램은 운영자의 Windows PC에서 실행됩니다. PC 앱의 브리핑·대화창에서 메일을 확인하고 자연어로 검색·요약·초안을 요청할 수 있습니다. 메일 내용과 관련 대화 및 사용자 지시는 OpenAI API로 분석합니다. 기존 알림과 초안은 운영자의 Slack 개인 대화로도 전달하며, PC 앱에서 요청한 초안은 앱에서 검토합니다. 공개 채널이나 그룹 대화에는 메일을 전달하지 않습니다. 아래 개인정보처리방침에서 처리 방식을 확인할 수 있습니다.

개인정보처리방침

적용 대상: Jake Kim이 본인의 메일 업무를 위해 운영하는 개인용 Gmail 비서

1. 접근하는 정보와 이용 목적

연결된 Gmail의 발신자·Reply-To·수신자 등 헤더, 제목, 본문, 관련 대화와 기존 발신 기록, 메시지 식별자, 라벨 및 시각을 읽습니다. 첨부파일은 파일명과 존재 여부만 확인하고 파일 내용은 다운로드하거나 분석하지 않습니다.

이 정보는 메일 분류·요약, 일정·마감 확인, 답장 초안 작성·수정, 기존 회신 확인, 중복 처리 방지 및 사용자 승인에 따른 발송에 사용합니다. 기존 라벨과 읽음 상태를 유지하고 자동 삭제하지 않습니다. 발송 성공 후 봇이 추가한 ‘답장 필요’ 라벨만 해제합니다.

2. 외부 서비스로 전달하는 정보

  • OpenAI API: 분류·요약·초안 작성과 수정을 위해 메일 내용, 관련 대화 및 사용자 수정 지시를 전달합니다. 요청에는 store=false를 설정합니다. 이는 제공자 측의 모든 보관이 없다는 뜻은 아니며, 보안·오남용 방지 보관 등에는 제공자의 정책이 적용됩니다. 인증정보와 API 키는 모델 입력에 포함하지 않습니다.
  • Slack: 발신자, 제목, 핵심 요약, 일정·마감, 라벨, Gmail 링크, 답장 수신자·제목·본문과 처리 결과를 운영자만 참여하는 개인 대화로 전달합니다. 메시지의 보관·삭제에는 워크스페이스 정책도 적용됩니다.
  • Google: Gmail API를 통해 위 기능을 수행하고, 사용자가 승인한 답장을 해당 수신자에게 전달합니다.

3. 판매·광고·학습 이용 제한

Google 사용자 데이터를 판매하거나 광고 타기팅, 신용 평가 또는 일반 목적 AI 모델의 개발·학습을 위해 사용하지 않습니다. 데이터는 설명한 개인 메일 보조 기능에 필요한 범위에서만 처리합니다.

Gmail 비서가 Google API에서 받은 정보를 사용하거나 다른 앱에 전달하는 행위는 Limited Use 요건을 포함한 Google API Services User Data Policy를 준수합니다.

4. 로컬 저장과 보호

처리 기록, 요약과 초안 버전, 승인·발송 상태 및 PC 앱 대화 기록은 운영자 PC의 SQLite에 저장합니다. 대화 입력과 필요한 메일 맥락은 응답·검색·초안 작성을 위해 OpenAI API에 전달합니다. 대화 세션은 최근 최대 7회 왕복을 암호화해 보관하며, 긴 대화의 이전 맥락은 일부 제외될 수 있습니다. 메일 내용·초안·대화 등 민감한 저장 필드와 새 인증정보는 Windows 사용자 DPAPI로 암호화합니다. 기존 OpenAI 키는 기존 저장 위치에서 읽습니다. 운영 로그에는 메일 본문이나 키 값을 기록하지 않습니다. 이 공개 안내 페이지에는 인증정보나 메일 데이터를 저장하지 않습니다.

5. 보관 기간·연결 해제·삭제

로컬 처리 기록과 암호화된 초안에는 현재 자동 만료 기간이 없으며 운영자가 삭제할 때까지 보관합니다. 운영자는 프로그램을 중지한 뒤 로컬 데이터와 인증 파일을 삭제할 수 있습니다. Google 계정의 타사 연결 관리에서 접근 권한을 철회하고 Slack 앱 연결을 해제할 수도 있습니다.

연결 해제만으로 기존 Gmail 메일, Slack 메시지 또는 이미 전달된 데이터가 자동 삭제되지는 않으며 각 서비스에서 별도로 관리해야 합니다. 외부 서비스의 보관에는 각 제공자의 정책이 적용됩니다.
